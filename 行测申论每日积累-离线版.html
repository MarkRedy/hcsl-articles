每日更新逻辑

每天首次打开自动抓取当日内容（按日期缓存，保留最近 7 天），之后打开秒开；点「⟳ 刷新」可随时手动更新。中新网各频道为直连抓取；「人民时评 / 上海要闻 / 国务院政策」为网页抓取，依赖公共跨域代理，速度较慢且偶尔失败（失败时红点，改天或换网络再试即可）。

关于「人民日报」「上海发布」

人民网官方 RSS 已于 2025 年停更，本页改从「人民时评」频道网页聚合人民日报评论文章（申论范文）。「上海发布」为微信公众号、无公开 RSS，本页以上海市政府官网「要闻动态」替代；如需公众号原文，可在 RSSHub 等自建服务生成 RSS 后，于「源设置 → 添加源」粘贴地址。

源设置 ✕

支持任意 RSS 2.0 / Atom 地址。抓取顺序：浏览器直连 → rss2json（限 10 条）→ 公共代理。中国大陆网络下，公众号 RSS 可用自建 RSSHub 生成。

使用说明 ✕

用途：每天自动收集与行测（常识、时政）、申论（热点、范文）、面试相关的文章，自动打标签、可搜索、可收藏导出。

分类：页面按关键词自动打标 —— 申论范文 / 上海 / 政策热点 / 常识·科技 / 常识·人文 / 常识·法律 / 民生热点 / 国际视野，点顶部标签筛选。

收藏导出：点卡片右上角 ☆ 收藏；「收藏夹」里可查看；「复制清单」把当前筛选结果复制为 Markdown 链接清单，可粘进笔记软件。

打不开数据？本页为本地单文件，建议用 Chrome / Edge 直接双击打开。若浏览器限制本地页面的网络请求，可在本目录运行 python -m http.server 8000 后访问 http://localhost:8000。

代理波动：「人民时评 / 上海要闻 / 国务院政策」三个网页源经公共代理抓取，公共代理偶尔限流（红点 = 今日该源未取到）。刷新按钮会重试；中新网八个频道不受影响。
