数据与抓取

数据保存在同目录 hc_articles.db（SQLite）：文章按 URL 去重、永久累积，可按日期回看历史；收藏与来源配置也在库里，换浏览器同样生效。抓取由本地 hc_server.py 完成，不走公共代理，稳定可靠；页面「⟳ 刷新」即触发一次抓取。想每天无人值守定时入库，可挂计划任务：python hc_server.py update。

关于「人民日报」「上海发布」

人民网官方 RSS 已于 2025 年停更，本页从「人民时评」频道聚合人民日报评论文章（申论范文）。「上海发布」为微信公众号、无公开 RSS，以上海市政府官网「要闻动态」替代；如需公众号原文，可自建 RSSHub 后在「源设置」添加其 RSS 地址。

源设置（保存在数据库，对所有浏览器生效） ✕

RSS 2.0 / Atom 均可，服务器端直连抓取（无跨域限制）。公众号 RSS 可用自建 RSSHub 生成。

使用说明 ✕

启动：本页需配合 python hc_server.py 运行，浏览器访问 http://127.0.0.1:8642/。服务启动时会自动补抓当天缺失的数据。

分类：抓取时按关键词自动打标 —— 申论范文 / 上海 / 政策热点 / 常识·科技 / 常识·人文 / 常识·法律 / 民生热点 / 经济金融 / 国际视野，点顶部标签筛选。

历史：所有入库文章永久保留，用顶部「查看历史」选日期回看；收藏夹长期有效。

收藏导出：点卡片右上角 ☆ 收藏（入库）；「复制清单」把当前筛选结果复制为 Markdown 链接清单。

定时抓取：Windows 计划任务执行 python hc_server.py update（抓完即退出），例如每天 08:00。启动方式：schtasks /create /tn "时政日报" /sc daily /st 08:00 /tr "python D:\dev\hc-articles\hc_server.py update"

登录

账号保存在本机数据库 hc_articles.db；收藏按账号隔离，登录后在自己设备上同步可见（服务同一台主机时）。
