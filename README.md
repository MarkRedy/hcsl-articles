# 行测申论 · 每日时政积累（SQLite 版）

本地抓取 + SQLite 存储 + 网页浏览，无第三方依赖（纯 Python 标准库）。

## 使用

```bat
cd /d D:\dev\hc-articles
python hc_server.py
```

然后浏览器打开 <http://127.0.0.1:8642/>（服务启动时会自动补抓当天缺失的数据；之后每次点页面上的「⟳ 刷新」即可更新）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `hc_server.py` | 抓取器 + SQLite 存储 + 本地 API + 静态服务（纯标准库） |
| `hc_articles.db` | SQLite 数据库（自动生成）：文章、收藏、来源配置 |
| `行测申论每日积累.html` | 前端页面（读数据库，需配合 hc_server.py） |
| `行测申论每日积累-离线版.html` | 旧版单文件方案（localStorage，无需 Python，应急可用） |

## 数据与抓取逻辑

- **账号**：打开页面需注册 / 登录（数据存在本机数据库）。密码用 PBKDF2-SHA256 加盐哈希存储，登录态为 HttpOnly Cookie（30 天有效）；**收藏按账号隔离**。第一个注册的用户会自动继承此前（无主）的收藏。
- **抓取**：服务器端直连，无浏览器跨域/公共代理问题。中新网 8 个频道 RSS（要闻/国内/国际/法治/文化/教育/财经/社会）+ 网页源（人民时评、上海市政府要闻动态、国务院最新政策，默认后一个关闭）。
- **入库**：按 URL 和标题去重，**永久累积**；`first_seen` 记录入库日期，页面顶部「查看历史」可选日期回看。
- **自动打标**：入库时按关键词打标 —— 申论范文 / 上海 / 政策热点 / 常识·科技 / 常识·人文 / 常识·法律 / 民生热点 / 经济金融 / 国际视野。
- **收藏**：存在数据库 `favs` 表，长期保留，换浏览器打开同样生效。
- **单次抓取约 1~2 秒**；有硬超时保护，单个源失败不影响其它源（源状态圆点标红）。

## 每天定时抓取（可选）

页面只在打开时展示数据，可挂 Windows 计划任务每天早上自动入库一次（抓完即退出）：

```bat
schtasks /create /tn "时政日报" /sc daily /st 08:00 /tr "python D:\dev\hc-articles\hc_server.py update"
```

## 添加 / 调整来源

- 页面「源设置」里可开关、增删 RSS 源，保存在数据库（对所有账号生效）；
- 也可直接改 `hc_server.py` 顶部的 `DEFAULT_SOURCES`，再在源设置里点「恢复默认源」；
- 公众号（如「上海发布」「人民日报评论」）没有公开 RSS，需要自建 [RSSHub](https://docs.rsshub.dev/) 生成地址后添加。

## 分享给同学（局域网）

默认只监听本机。想让同一 WiFi 下的设备（手机 / 平板）访问，可改为监听局域网并开放端口：

```bat
python hc_server.py --host 0.0.0.0 --port 8642
```

其他设备访问 `http://<你的内网IP>:8642/`，各自注册账号登录即可（收藏互相隔离）。注意：开放后同一网络内的人都能注册，请勿在公共网络使用。

## 关于「人民日报」「上海发布」

- 人民网官方 RSS 已于 2025-06 停更，人民日报内容改从「人民时评」频道聚合（壹时评、人民时评等，即申论范文）。
- 「上海发布」为微信公众号、无公开 RSS，以上海市政府官网「要闻动态」替代（同时会收录该页内嵌的国务院要闻）。
